# Changelog

## 1.0.0 - 2026-10-16

- First release of the Lite edition: device tracking (keyboard, gamepad with family, touch), virtual joystick (fixed, floating, following; deadzone, curve, 8 directions), multi-touch buttons (slide on, toggle, shapes), safe area. Class names `PipaloLite*` and autoload `PipaloLite`, so it never clashes with the full Pipalo.
